Using Python build an application with the following features / functions:

Add two floating point numbers and display the result.

Using the FastAPI package for Python the application should provide a HTML
front end accessible in a browser over a local Ethernet connection.

The Web front end should have a caption named "Adding two numbers"

It should have a text entry form field for:
The first argument and a caption "First Number"
The second argument and a caption "second number"
The result and a caption "result"

Below these fields there should be a push button with a label "Calculate"
Upon the button pressed the Python script should read the first argument,
the secoond argument and display the result in the "result" field.

The HTML front end should have a dark blue background and white colored fonts.
